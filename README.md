# Özgeçmiş

Özgeçmiş bilgilerini gösteren web uygulaması.

## Ne var

Ana sayfa `HomePageController` içindedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework MVC, Entity Framework ve Database First.
